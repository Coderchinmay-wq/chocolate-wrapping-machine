# chocolate-wrapping-machine
A prototype of chocolate wrapping machine designed and developed as a first-year Engineering Exploration project using CAD modelling, microcontroller Arduino Mega 2560 and a mechanical conveyor-based wrapping mechanism.

## Overview

This project presents a prototype Chocolate Wrapping Machine developed as part of the Engineering Exploration course. The objective was to understand the engineering design process by designing, modelling, and fabricating a simple automated wrapping mechanism capable of demonstrating chocolate transportation and wrapping.

## Objectives
Understand the product design cycle
Learn CAD modelling
Build a functional prototype
Study conveyor mechanisms
Estimate embodied energy and material usage

## Features
✔ Conveyor based transportation

✔ Wrapping mechanism

✔ Acrylic body

✔ DC motor driven movement

✔ CAD model before fabrication
